# Vanilla-with-Sprinkles-Ru

Информация: Перевод достижений в датапаке Vanilla with Sprinkles. Ссылка на [датапак](https://www.curseforge.com/minecraft/customization/vanilla-with-sprinkles)

Установка: Пример для Prism Launcher:

Скопировать с заменой файлы в корневую директорию модпака. Например, C:\Users\User\AppData\Roaming\PrismLauncher\instances\VwS\minecraft\saves\NewWorld\datapacks

После запустите игру и проверьте работу перевода.

Если найдёте какие-то ошибки, можете сообщить о них мне в дискорд: narik_20
